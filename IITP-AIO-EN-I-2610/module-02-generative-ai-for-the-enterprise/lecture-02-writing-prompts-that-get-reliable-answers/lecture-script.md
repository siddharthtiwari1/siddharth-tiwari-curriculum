## Topics

- Writing a prompt as a brief: goal, audience, format, limits
- Zero-shot and few-shot prompting: no examples, or a few examples, in the prompt
- A system prompt: fixing role, scope and limits
- Fixing a weak prompt one change at a time
- Checking an AI draft against your stated limits before you use it (a self-check)
- Your team's prompt library: the prompt, the model, the settings (parameters) and what went wrong
- Hands-on: Write a system prompt for one task you repeat, rewrite a weak prompt from your own work three times and compare the answers, then save the best version as the first entry in your team's prompt library

## Learning objectives

- Write a zero-shot prompt that states the task, the input and the expected output
- Compare zero-shot and few-shot prompting by the task types each suits
- Write a system prompt that fixes the assistant's role, scope and constraints
- Debug a prompt that produced a wrong answer by changing one instruction at a time
- Apply self-correction by asking the model to critique and revise its own output
- Build a prompt library entry recording the prompt, model, parameters and known failures
