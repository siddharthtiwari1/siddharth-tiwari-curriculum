## Topics

- Contract field extraction
- Source citations
- Checking summaries against clauses
- Which outputs need a lawyer's review
- Hands-on: Extract the key fields from a supplied scanned contract with AI as JSON (a list of field names and their values) and verify each against the original

## Learning objectives

- Extract structured fields from a document image into JSON
- Construct an AI-generated output that attaches a supporting source to each claim
- Classify a generated claim as grounded in or unsupported by the provided context
- Evaluate which automated decisions need a human reviewer, justifying by severity and reversibility
