## Topics

- LangChain and LangGraph: code libraries your engineers build with, Dify and n8n: visual tools your own teams can build with
- No-code or custom code for a use case, and what each choice implies for hiring, speed and lock-in
- Evidence to ask vendors for before you scale
- Hands-on: Score a supplied agentic-vendor proposal for improving operations at an automobile service centre against integration, guardrail and observability needs

## Learning objectives

- Compare agentic platforms by how much of the build is no-code versus custom code, for a stated use case
- Select a no-code platform or custom code for a requirement, justifying by scale and customisation
- Classify an AI vendor's claim as backed by verifiable evidence or as an unverifiable superlative
- Evaluate a GenAI vendor proposal against a stated set of enterprise requirements, scoring each requirement met or gapped
