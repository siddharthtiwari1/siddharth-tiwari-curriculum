## Topics

- One agent or several
- Supervisor and specialist agents (multi-agent orchestration)
- Handing work between agents
- Roles and tools for each agent
- How agents from different vendors pass tasks to each other (the A2A standard)
- Hands-on: Build a supervisor step in Dify that sorts each request and passes it to one of two specialist agents, the instructor walks through one A2A task exchange

## Learning objectives

- Select a single agent or a multi-agent team, justifying by the count of independent subtasks
- Build a multi-agent team where a supervisor delegates subtasks to specialist agents
- Configure the handoff between two agents so context passes with the task
- Configure the role and permitted tools of a no-code agent
- Describe how two independent agents exchange a task and its result over an agent-to-agent protocol
