## Topics

- Test and production (the live version people use): a dry run on sample data
- Publishing an assistant as a web app
- Keys and passwords as stored secrets
- What observability is
- Sampling live answers
- Why pilots fail in production
- Hands-on: Dry-run your Dify assistant on sample requests, check its model key is stored as a secret, publish it as a web app, have a classmate use it, then sample ten answers from its logs and score them in a sheet

## Learning objectives

- Test a workflow against sample data before enabling it on live events
- Deploy a no-code application to a shareable URL and confirm a new user can use it
- Configure an application credential so a workflow node authenticates successfully
- Describe what observability means for an agent, including what is recorded at each step and who reviews it
- Sample production traffic for human review of response quality
- Explain why an agent pilot that works in a demo can fail in production
