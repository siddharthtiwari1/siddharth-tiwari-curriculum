## Topics

- What makes a system an agent: autonomy, memory and the ability to act
- Suggesting versus acting: a copilot suggests and you decide, an agent acts, with agent products on the market (instructor demo)
- Agent memory
- Using the result of one step to choose the next
- Reading an agent's run log (its step-by-step record)
- Hands-on: Run a supplied Dify agent on three sample customer requests and name the action it took at each step of its log

## Learning objectives

- Describe what makes a system an agent rather than a single LLM call
- Compare a copilot with an agent by whether a person approves each step
- Describe what memory lets an agent do that a single chat reply cannot
- Explain how a tool's result re-enters the prompt on the next iteration
